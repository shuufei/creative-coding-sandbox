# creative-coding-202607

p5.js + TypeScript + Vite によるクリエイティブコーディング実験環境。

## セットアップ

```sh
npm install
npm run dev
```

ブラウザで `http://localhost:5173` を開く。

## スケッチ一覧 (インデックスページ)

ルート (`http://localhost:5173/`) は登録済みスケッチの一覧ページ。
各スケッチを画面外で実際に 1 回走らせ、その描画結果を縮小したものをサムネイルに使う
(実装: `src/gallery.ts`)。

- カードをクリックするとそのスケッチを開く
- カード右上の `↻` でそのサムネだけ再生成 (パターンは毎回ランダム)
- ヘッダーの「すべて再生成」で全部作り直す
- サムネは sessionStorage にキャッシュされるので、一覧とスケッチの行き来では再生成しない

## スケッチの切り替え

`src/sketches/index.ts` にスケッチを登録している。URL クエリで直接開くことも可能:

- `http://localhost:5173/?sketch=random-geometry`
- `http://localhost:5173/?sketch=color-grid`

スケッチ表示中は左下の `← index` で一覧に戻る。

## 設定パネル

一部のスケッチは canvas の下にパネルを出して、その場でパラメータを変えられる
(`random-geometry` / `triangle-grid-50`)。値を変えるとその場で描き直す。

- `triangle-grid-50`: マス数 (30x30 / 50x50 / 100x100)、塗り方、同色の隣接上限
  (2 = 幅1の帯 / 3 = 塊)、帯の長さ、帯の色 (単色 / 明度違い5色)、塊の大きさ、
  埋め草と帯の面積比 (項目は塗り方によって出し入れされる)

`triangle-grid-50` の塗り方は4種類:

| 塗り方 | 内容 |
| --- | --- |
| 白 + 2色 / 連結あり | 白地に、2色を指定の長さの帯として連結させて敷く |
| 白 + 2色 / 連結なし | 連結の制約なしで、三角形ごとに面積比だけを重みに色を選ぶ |
| 下地 + 帯 / 白なし | ランダムな1色の下地の上に、もう1色を指定の長さの帯として塗る |
| 2色の塊 / 白なし | 2色を交互に、ランダムな場所に指定の大きさの塊を白がなくなるまで敷き詰める |

`白 + 2色 / 連結なし` のときだけ「1マスの塗り分け」を選べる。

| 1マスの塗り分け | 内容 |
| --- | --- |
| 標準 / 面積比でランダム | マスは意識せず、三角形ごとに面積比だけを重みに色を選ぶ |
| A / 近い2色 + 遠い2色 | 色相の近い2色 + そこから色相の遠い2色 |
| B / 4つのうち2つだけ | 1マスの4つの三角形のうちランダムな2つだけを塗る (残り2つは白) |
| C / 近い4色 | 色相を少しずつずらした4色 |
| D / 色相が均等な4色 | 色相を90度ずつ均等に離した4色 |
| E / 近い3色 + 遠い1色 | 色相の近い3色と、そのかたまりから色相を離した1色 |
| E-2 / 遠い1色は同じ位置 | E と同じ4色で、遠い1色をどのマスでも同じ位置 (上/右/下/左のどれか) に置く |
| E-3 / 遠い1色を時計回りに | E と同じ4色で、遠い1色の位置を上 → 右 → 下 → 左 と1マスずつずらす |
| E-2b / 明度違い3色 + 遠い1色 | E-2 の近い3色を、1色の明度を 16 ずつ落とした3段に置き換えたもの |

B 以外はどれも「4色を1マスに1色ずつ置く」で、違いは色相の散らし方と並べ方だけ
(いずれも白は使わない)。E-2 / E-3 は遠い1色の位置だけをルールで決め、
残りの近い3色はマスごとにシャッフルして空いた場所に入れる。位置の起点は描くたびに
ランダムに選ぶ。

`下地 + 帯 / 白なし` のときだけ「帯の色」を選べる。`明度違い5色` にすると、帯の色の
明度を 11 ずつ落とした5色から、帯を構成する三角形1つごとにランダムで1色を選んで塗る。
